# Next.js + TypeScript + SASS Modules + MobX (Minimal Starter)

## Установка
```bash
pnpm i   # или npm i / yarn
pnpm dev # http://localhost:3000
```

## Что внутри
- Next.js (App Router)
- TypeScript (strict)
- SASS/SCSS + .module.scss
- MobX + mobx-react-lite
- Глобальный провайдер стора и пример счётчика
